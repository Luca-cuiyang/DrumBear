# DB Score 账户中心（个人中心）设计方案 v2

> 目标：把「账户中心」升级为专业、完整的个人中心，覆盖账号、会员、作品、成长、支持五大能力。
> 本方案为 UI/交互/信息架构设计，确认后再进入开发。

## 一、整体框架

### 布局

- 左侧：竖向二级导航，分 5 组，带分组标题与图标。
- 顶部：账号信息条常驻（头像、昵称/手机号、会员徽标、开通会员按钮）。
- 右侧：内容区随选中项切换，滚动展示。

### 左侧导航结构

```
[账号信息条 - 常驻顶部]

账户
  账号概览
  我的会员
  订单记录

作品
  我的工程
  我的乐谱
  制谱记录

成长
  积分中心
  推广赚佣
  软件分享

支持
  帮助中心
  联系客服

[底部]
  设置
  退出登录
```

## 二、各页面设计

### 1. 账号概览（默认页）

- 未登录：合并式手机号登录卡（手机号 + 验证码 + 60s 倒计时 + 登录/注册），内联错误提示；登录成功自动刷新账号条与会员状态。
- 已登录：昵称、手机号、会员状态徽标、设备标识、退出登录。
- 快捷入口网格：我的工程、我的乐谱、制谱记录、推广赚佣、联系客服、帮助中心（4~6 个卡片入口）。

### 2. 我的会员

- 会员状态卡：试用中 / 正式会员 / 已过期（不同颜色徽标）、到期时间、剩余天数。
- 主操作：开通会员 / 续费 ¥199/年 → 打开 `drumbearai.com/membership`。
- 会员权益列表（音频 AI 对齐、动态工程、无水印 MP4 等）。
- 激活码兑换（备用入口，弱化）。

### 3. 订单记录

- 订单列表：订单号、套餐、金额、状态（待支付/已支付/已取消）、时间。
- 空状态：无订单时显示“暂无订单记录 + 开通会员引导”。
- 数据来源：后端 `/api/orders`、`/api/orders/payments`。

### 4. 我的工程

- 本地 `.db` 工程列表（最近打开 + 扫描工程目录）。
- 每项操作：打开、重命名、在访达中显示、删除（回收站）。
- 搜索框 + 排序（最近打开/最近修改/名称）。
- 空状态：无工程时显示“新建乐谱”引导。
- 会员专属「云端备份/同步」开关；未开通显示锁定徽标。

### 5. 我的乐谱

- 我发布到云端的乐谱：封面、标题、更新时间、公开/私密状态。
- 操作：打开、分享链接、删除、设为私密。
- 数据来源：云端乐谱接口（需 workbuddy 提供/补齐）。

### 6. 制谱记录

- 统计卡：累计制谱数量、总时长、本月新增（3 张数字卡）。
- 时间线列表：文件名、创建时间、时长、最近修改。
- 筛选：今天 / 本周 / 本月 / 全部。
- 数据来源：本地工程目录扫描；云端统计后补。

### 7. 积分中心

- 积分余额、每日签到按钮（签到送积分）。
- 积分明细流水。
- 说明：积分可用于推广/兑换（规则待定）。
- 数据来源：后端 `/api/points/checkin` 等（已有）。

### 8. 推广赚佣

- 我的邀请码 + 邀请链接 + 复制按钮。
- 邀请规则说明（好友注册并付费后返佣）。
- 佣金余额、佣金记录、提现申请。
- 数据来源：后端 `/api/invite`、佣金接口（需 workbuddy 确认用户端）。

### 9. 软件分享

- 分享文案 + 分享链接（`drumbearai.com/dbscore`）+ 二维码。
- 一键复制文案/链接。
- 纯前端，二维码本地生成或后端带参链接。

### 10. 帮助中心

- 新手引导、快捷键速查、视频教程入口。
- 分类 FAQ（激活、登录、会员、导出、音频）。
- 纯前端。

### 11. 联系客服

- 客服微信二维码、邮箱/QQ。
- 意见反馈表单（提交后端 `/api/feedback`）。

### 12. 设置 / 退出登录

- 设置：暂作为入口预留（可跳软件偏好设置）。
- 退出登录：清除本地 token，回到未登录态。

## 三、视觉与交互规范

- 深色主题，卡片圆角 12，卡片间距 16，内容内边距 20。
- 会员徽标配色：试用 = 橙、正式 = 绿、过期 = 红、免费 = 灰。
- 所有列表统一：搜索框、排序/筛选、空状态、加载态、操作按钮。
- 数字统计用大字号卡片，与正文区分。
- 关键动作（开通会员、登录）用主色 accent 按钮。

## 五、实施顺序

- 第一阶段（前端可独立完成）：账号概览、我的会员、订单记录、软件分享、帮助中心、联系客服、制谱记录(本地版)、我的工程(本地版)。
- 第二阶段（workbuddy 补接口后）：积分中心、推广赚佣。
- 第三阶段（后端云存储开发后）：我的乐谱(云端)、我的工程(云备份)、通知中心。
