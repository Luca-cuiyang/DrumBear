# DB绘谱 发布规范（硬性要求，锁死）

每次「打包 / 推送软件内更新 / 升级」都必须遵守以下规则：

1. **版本号自动 +1**
   - 唯一版本源：`release-version.txt`。
   - 每次发布递增 patch：`5.1.5 → 5.1.6 → 5.1.7 …`。

2. **桌面代码文件夹同步改名**
   - 桌面目录必须形如 `DB绘谱-v<版本>`，例如 `DB绘谱-v5.1.6`。
   - 发布时把旧目录重命名为新版本目录，并同步修正 CMake / 打包脚本里的绝对路径。

3. **只保留最新版本**
   - 发布成功后删除旧的 `DB绘谱-v*` 目录、旧 DMG/MSI、旧更新历史里非当前版本。

4. **升级全程全中文**
   - Mac / Windows 的更新提示、下载进度、安装界面、升级完成提示都必须为中文，
     不得出现英文。

5. **必须实测升级成功**
   - 推送更新信息后，分别在 Mac 和 Windows 各验证一次：
     老版本 → 收到更新提示 → 下载 → 安装 → 打开为新版本。

## 执行入口

```bash
bash buildscripts/release.sh
```

脚本自动完成：版本 +1 → 重命名桌面目录 → 修正路径 → 提交推送 → 触发自托管台式机打包。
打包完成后，执行本机直传脚本上传并更新更新源，再跑一遍升级验证：

```bash
bash buildscripts/ci/tools/upload_installer.sh <安装包> <windows|macos> db-score
```

Windows 只在自托管台式机 runner 打包，macOS 只在本机打包；禁止云端、禁止虚拟机。
