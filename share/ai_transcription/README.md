# DB绘谱 AI 转谱

AI 转谱是 `主页 → AI转谱 → 乐谱` 中的独立页面。当前版本只做架子鼓鼓谱，
统一处理两类输入：

- MIDI 鼓轨转 `.db` 鼓谱
- 图片或 PDF 鼓谱转 `.db` 鼓谱

页面设计稿见同目录的 `AI转谱页面设计方案.png`。

转换器不会把“生成成功”和“内容正确”混为一谈。最终文件必须通过严格校验。

## P1.0.0 运行库打包

图片和 PDF 识别依赖 `numpy`、`opencv-python-headless` 和 `Pillow`。正式
macOS 安装包必须内置便携 Python，不能依赖开发机上的虚拟环境：

```bash
cmake -S . -B build.release \
  -DMUSE_AI_TRANSCRIPTION_PYTHON_DIR=/path/to/portable-python
```

该目录应包含 `bin/python3`、`Python3` 和 `lib/python3.x/site-packages`。
安装后位于：

```text
DB绘谱.app/Contents/Resources/ai_transcription/python
```

macOS 打包脚本会执行 `import cv2, numpy, PIL`，任一项缺失都会拒绝生成安装包，
避免发布后在用户电脑上出现白屏或英文依赖错误。

## MIDI 转谱

1. MIDI 标准化器读取 Channel 10 鼓轨。
2. 保留每个不同的鼓件、击打时间和力度。
3. 自动识别直拍或三连音网格。
4. 自动把首镲的小幅延迟对齐到强拍；也可手动向前/向后调整
   `1/16`、`1/8`、`1/4`。
5. 原生生成 DB绘谱 双层鼓谱，不经过会移动音符的 MIDI 导入器。
6. 重新解析生成的 `.mscx`，要求 `(tick, pitch)` 与标准化 MIDI
   逐事件完全一致，否则不输出 `.db`。

报告中的 `exactTimelineMatch=true` 才是严格通过。

## 图片 / PDF 转谱

1. PDF 页面先按 300 DPI 渲染。
2. Audiveris 识别五线鼓谱和小节结构。
3. 转换器重建鼓件、节奏、符尾、符杠和上下声部。
4. 识别完成后创建持久化的“AI复核资料”工程，保留原图、逐页识别标记、
   合并事件表、拍号和小节结构。
5. AI页并列显示原谱和识别标记。无待确认事件、无自动纠拍且无休止符风险的
   小节标记为“自动通过”；只有存在推断或冲突的小节进入人工复核。
6. 可逐条修改拍位、删除识别错误的音符、新增漏掉的音符，并可按照修正后的
   拍位重新计算时值、符尾和符杠。
7. 自动通过和人工确认的小节都完成后重新执行严格转换；小节数量、小节时值、事件时间轴、
   鼓件映射、声部方向和 DB 压缩包完整性任一失败，都不生成最终 `.db`。
8. 把生成的谱面重新渲染，核对页数、每页系统数、每页小节数和拍号。
   二次 OCR 的鼓件差异只作为诊断资料，不覆盖已经通过原生谱结构校验的数据。
9. 正式文件旁生成 `quality-certificate.json`，记录复核数量、质量提示、
   版式结果和 `.db` 哈希。
10. 同一小节内的重复拍型必须保持同一套相对节奏。验收时可直接用一个已确认
    小节作为模板，比较音高、拍位、时值、附点、声部和符杠，而不是只看拍数。
11. 符杠组按“起点 + 印刷时值”整体重建，最后一个音符必须写入原生
    `BeamMode=end`。横向网格、声部脉冲或事件合并都不能拆开已经确认的符杠。
12. 休止符可以因排版省略而隐藏，但必须在复核事件表中显式标记为
    `hidden=true`；隐藏只影响显示，不改变时间轴。音高、时值、声部或休止符
    任一校验失败仍会阻止导出。
13. 连音/圆滑线只来自允许的鼓件端点；源图中不存在的曲线可列入
    `curve_removals`，删除曲线不会改动对应鼓点。

图片 OMR 不可能仅凭像素无损还原所有谱面语义。因此严格模式不会用
“猜测后继续输出”的方式掩盖错误；自动推断的小节必须复核后重新转换。

## 严格校验

以下任意一项失败都会阻止最终输出：

- MIDI 存在同一 tick、同一鼓件的重复事件，但未先经过标准化。
- 存在不支持的鼓件音高。
- 小节总时值与拍号不一致。
- 生成文件中的起音或鼓件与输入时间轴不一致。
- 上下声部或符干方向不符合 DB绘谱鼓谱规则。
- 图片识别存在未映射符头、未确认节奏或未通过结构检查。
- 休止符声部、拍位、时值、附点无法确认。
- 生成谱面的页数、系统数、每页小节数或拍号与源谱不一致。
- 生成的 `.db` 压缩包损坏。

## 休止符规则

- 休止符直接读取图片 OMR 中的休止符符号，不再由音符间距猜测。
- 支持全休止、二分、四分、八分、16 分、32 分和 64 分休止符。
- 通过 augmentation-dot / double-dot 关系保留附点和双附点。
- 休止符按谱表上的垂直位置分成上声部与下声部，复核页会明确显示声部。
- 双声部中，下声部最后一个底鼓/踩镲音符之后的时间用隐藏休止填补；
  两个下声部音符之间的休止符保持可见。
- 上声部的空拍休止保持可见；只有底鼓而没有上声部内容时保持单声部谱。

复核资料默认保存在输出文件旁：

```text
曲名-AI复核资料/
├── input-pages/          # PDF 渲染页，或原始图片
├── work/                 # OMR、逐页事件表、识别标记图
├── manifest.json
└── review.json           # UI 读取和保存的逐小节确认状态
```

如果所选图片与内置清单中的同一套曲目页面完全匹配，转换器会复用已经确认的
拍号、拍位修正和版面分段，再进入人工复核；新曲目或页面组合不完全一致时会
自动使用新生成的识别结果。

当前四首核心回归样本为《推进式飞机》《LATIN》《Rock》《摇滚派对》。
全部 8 首黄金样本还必须通过数据库时间轴摘要、自动化回归测试、
原生 MSCX 结构校验和逐页视觉证明。
